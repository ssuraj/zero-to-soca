# Zero to SOC

**A Budget-Friendly Roadmap to Your First Cyber Security Job**
*Learn. Detect. Defend.*

By **Suraj Wagh** | First Edition, 2026

---

## About this book

*Zero to SOC* is a practical guide for engineering and IT graduates, career changers and working IT professionals who want to start a career as a **SOC (Security Operations Center) Analyst**. It uses free and low-cost resources and focuses on hands-on practice.

## Download

Get the PDF from the **[Releases page](../../releases/latest)** (file: `Zero_to_SOC_Book.pdf`).

## What is inside (104 pages)

- Technical foundations: networking, Linux and Windows, security basics
- Core SOC skills: logs and SIEM (Splunk), alert triage, incident response, phishing analysis, threat intelligence, MITRE ATT&CK, Wireshark
- Hands-on practice: home lab guide, practice platforms, three sample investigation write-ups
- Career: 16-week study plan, certifications, resume, interviews, job hunt, first 90 days, career paths and ethics
- A quiz after every chapter (18 quizzes) with an answer key
- Cheat sheets, resource directory, checklists, glossary, index and reference list

## Who it is for

- Fresh IT or engineering graduates
- People working in IT who want to move into security
- Anyone who wants a structured, low-cost path into cyber security
